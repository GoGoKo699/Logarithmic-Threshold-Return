## What a verification run means

`python verify.py --output-dir verification-artifacts` requires a fresh output directory.
It checks the imported inputs, runs only the active suites, preserves their logs and
observed JSON, and writes complete field differences against the saved references.
Timeouts, invalid outputs, changed scientific metadata/structure and out-of-threshold
numeric changes fail the run. Only the top-level environment and date fields are treated
as descriptive metadata. Integer counts, status strings and scientific parameters are
not silently exempted. The first hosted comparison exposed eight differences in suite
07's recorded solver-evaluation counts. After checking their exact source assignments,
a narrowly scoped workload review was added for those explicit paths. Raw failed flags
remain in each comparison, and ordinary counts, changed types and physical values still
fail. The general floating threshold was not changed.
[HOSTED_IMPORT_REVIEW.json](HOSTED_IMPORT_REVIEW.json) preserves the failed-run evidence
and the source-based classification; the rule was added after inspection, not claimed
to be predeclared.

The default numeric regression threshold is an absolute 1e-10 plus a symmetric relative
1e-9. It is an infrastructure alert, not a rigorous solver-error estimate or permission
to change a scientific claim. It was set before inspecting a hosted import run. All raw
differences and byte-equality flags remain visible, including differences that pass this
alert threshold. A changed benchmark needs its own source-level investigation, not a
wider threshold selected for a green check.

The original assertions must also pass and their reported group/case counts must match
the registry. Five suites contain 28 groups and 272 controls. Tooling unit tests and
repeated executions are not added to those scientific counts. No previous research
archive is imported or executed as a dependency of a current test.

A fresh local baseline ran the five source suites in separate processes and reproduced
every saved result byte-for-byte. [INITIAL_VALIDATION.json](INITIAL_VALIDATION.json)
records the completed executions. This was an author-side run in the recorded local
environment, not an independent review or proof. Container Git cloning failed on DNS;
the local source came from the supplied archives and was matched to Git object identities.

Hosted verification retains actual observations, comparisons, an environment report,
and the tracked source archive, including on failure. Read its actual run before
claiming hosted success. Artifacts have a finite retention period; the original input
identities and historical validation records remain in Git. Neither a pass nor exact
reproduction settles scientific priority, correctness or apparatus feasibility.
